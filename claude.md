# Compound — Personal Finance App

Single-file app: index.html at repo root. Vanilla JS, no frameworks, no build step.
Data persists via localStorage — never rename localStorage keys.

Key rules:
- One concern per prompt. Don't touch unrelated tabs or sections.
- Preserve all localStorage key names exactly.
- Do not split index.html into multiple files.
- Do not add external libraries or a build step.
- Dark card styling throughout — match existing component patterns.
- When moving UI between tabs, only change placement, not data structure.

See project SKILL.md for full context: tab structure, metric definitions, design conventions.
